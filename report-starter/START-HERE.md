# ⭐ Report Starter Kit — בסיס לדוחות אינטראקטיביים

ערכת התחלה נקייה לבניית StoryReport ממותג בכל פרויקט חדש. **העתק את כל התיקייה הזו**
והתחל לעבוד.

## להתחיל ב-30 שניות
1. **פתח את `Report.html`** בדפדפן — תראה דוח-דוגמה מלא עם כל סוגי הסקשנים.
2. לחץ **✏️ עריכת טקסט** (כפתור צף שמאל-תחתון) וערוך טקסט במקום. נשמר אוטומטית.
3. החלף את `assets/logo.jpg` בלוגו שלך.

## שלוש דרכים לערוך (פירוט מלא ב-`template/AUTHORING.md`)
- **✏️ מצב עריכה** — הכי מהיר, בתוך הדפדפן, ללא קוד.
- **Markdown** — ערוך `template/content.md`, בקש מסוכן *"apply content.md"*.
- **קונפיג** — ערוך ישירות את `window.REPORT` ב-`template/content.js`.

## מה כלול
```
Report.html          ← פותחים את זה
Report Editor.html   ← עורך Markdown עם תצוגה חיה (אופציונלי)
assets/logo.jpg      ← הלוגו (להחליף)
template/
  content.js / .md   ← תוכן הדוח (דוגמה — להחליף)
  brand.css          ← מערכת עיצוב (3 ערכות נושא) — לא לגעת
  charts.js          ← מנוע גרפים SVG — לא לגעת
  render.js          ← בונה את הדוח — לא לגעת
  edit-mode.js       ← מצב עריכה WYSIWYG — לא לגעת
  AUTHORING.md       ← המדריך המלא + סכמה
```

## טיפים
- **ערכת נושא / צבע / צפיפות:** לוח ה-Tweaks בדוח (פינה).
- **דוח מבוסס-נתונים (מספרים/גרפים מחושבים) או גרפים אינטראקטיביים:** ראה את הסעיף
  *Advanced — data-driven & interactive* ב-`AUTHORING.md`. דוגמה מלאה: פרויקט חזרת
  העסקים (`build_business_storyreport.py`).
- **להטמיע עריכות לצמיתות:** במצב עריכה → **⬇ ייצוא עריכות** → מסור את הקובץ לסוכן.
