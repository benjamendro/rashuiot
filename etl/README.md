# ETL — בסיס נתונים מאוחד לרשויות המקומיות (למ"ס)

צנרת שמאחדת את קבצי "הרשויות המקומיות בישראל" של הלמ"ס לכל השנים לבסיס נתונים אחד.
כל 255 הרשויות נשמרות (נדרש לחישוב בנצ'מרקים ארציים ולפי אשכול חברתי-כלכלי);
רשויות האשכול (גליל מזרחי/מערבי) מסומנות לפי `eshkol-matching/eshkol_mapping.xlsx`.

```bash
pip install -r etl/requirements.txt
python -m etl.run          # שלבים 0-2, כ-2 דקות
python -m pytest tests     # בדיקות
```

## ממצאים חשובים בנתוני המקור

1. **`p_libud_2019.xlsx` הוא בפועל קובץ 2022** (כותרת "רשויות מקומיות 2022", זהה תא-לתא ל-`p_libud_22.xlsx`
   אחרי הסרת שתי עמודות שנוספו). מוחרג. **חסרים 2016 ו-2019** — הורדה מ-cbs.gov.il חסומה מסביבת הענן;
   יש להעלות ידנית ולהוסיף שורה ב-`etl/config/sources.yaml`.
2. **סמלי מועצות אזוריות**: עד 2023 דו-ספרתיים (הגליל העליון `01`), מ-2024 `5500+n` (`5501`).
   מנורמל לסכמת 2024. בלי זה ראש פינה (`26`) מתנגש במטה יהודה (`26`).
3. **כותרות**: 2014–2015 — שורת כותרת אחת עם השנה בתוך הטקסט ושני גיליונות נפרדים (עיריות+מ"מ / מ"א);
   2017+ — 3–5 שורות כותרת. ב-2020+ אין תאים ממוזגים: תווית קבוצה כתובה באמצע בלוק שגבולותיו מסומנים
   ב-borders, ולכן הטווח משוחזר מהגבולות (`etl/headers.py`).
4. **תקופת נתון ≠ שנת קובץ**: לכל עמודה נשמר `data_period` (למשל בקובץ 2024 השכר הוא 2023, החינוך תשפ"ד).
   קבצי 2014–2015 מכילים לעיתים שתי שנים של אותו מדד (ארנונה 2013 ו-2014).
   נתונים סטטיים חוזרים בכמה קבצים (שימושי קרקע 2013 בקבצי 2014–2020) — ייפתר בשלב 3 לפי `data_period`.
5. **שורות סיכום של הלמ"ס**: ב-2022 שורת "כלל ארצי" של "הכנסות לנפש" היא *סכום* ערכים לנפש (2.4 מיליון) —
   אין להשתמש בה כבנצ'מרק כמות שהיא.
6. **סכום הרשויות < "כלל ארצי"** בכ-60–80 אלף נפש בכל שנה (אוכלוסייה שאינה בתחום רשות מקומית).
   כלומר "כלל ארצי" הרשמי ≠ סכום/ממוצע 255 הרשויות — שני הבנצ'מרקים יוצגו בנפרד בשלב 4.

## יחידות — ממתין להחלטה (שום דבר לא הומר)

`data/silver/units_review.csv` — עמודת `decision` למילוי. עיקרי הממצאים:

* **אוכלוסייה / גברים / נשים**: באלפים עם ספרה עשרונית אחת עד 2017 (32.9 = 32,900±50), מוחלט מ-2018.
  המרה ×1000 לא משחזרת דיוק.
* **2018 גברים/נשים**: הכותרת אומרת "(אלפים)" אבל הערכים מוחלטים — שגיאת כותרת של הלמ"ס.
* **יחס גבייה בארנונה למגורים (%)**: ב-2022 נשמר כשבר (0.75) ולא כאחוז (75).
* **אוכלוסייה בשימושי קרקע**: "סוף 2013" באלפים, "סוף 2021" מוחלט.
* שינויים קטנים מ-×10 (למשל ל-1,000 מול ל-100,000) לא מזוהים אוטומטית — רק דרך שינוי בתווית.

## איך לבדוק את מיפוי המדדים

`column_map_DRAFT.csv` — שורה לכל עמודת מקור. עמודות מפתח:
`indicator_id`, `levels` (הכותרת המקורית), `matched_to`, `match_method`
(`exact` → `unit_variant` → `leaf` → `tokens` → `fuzzy` ≥0.85 → `new`),
`corr_with_newer_year` (מתאם Spearman עם אותו מדד בשנה החדשה הבאה, לפי סמל רשות),
`review_needed` / `review_reason`.

תיקון ידני: שורה ב-`etl/config/column_overrides.csv` (`year,sheet,col,indicator_id`) — או `NEW`
כדי להפריד עמודה. מזהי המדדים יציבים בין ריצות (hash של תווית העוגן).
